# SPA 命令面板使用指南 / SPA Command Palette Guide

本文档详细介绍 Stellarsis SPA 版本命令面板的使用方法。

## 概览 / Overview

命令面板是一个快捷命令系统，提供键盘驱动的快速导航和操作界面。

**核心特性**:
- 🔑 按 `:` 键快速打开
- ⌨️ 模糊搜索支持
- ⏎ Tab 自动补全
- 💡 智能命令建议
- 📜 命令历史记录（最近执行的命令优先显示）
- 📋 完整命令列表（输入 `help` 查看）

---

## 快速开始

### 打开命令面板

在任何页面（非输入框焦点状态），按 `:` 键即可打开命令面板。

### 基本使用

1. 输入命令名称（如 `help`）
2. 按 Enter 执行
3. 按 Tab 自动补全
4. 按 Esc 关闭面板

### 示例

```
:help              # 显示所有可用命令（完整列表）
:go home           # 返回首页
:theme dark        # 切换到暗色主题
:focus message     # 聚焦到消息输入框
```

## 特性说明

### 1. 模糊搜索

支持模糊匹配，输入部分命令名即可找到：

```
输入: go   -> 匹配: go home, go chat, go forum, go settings, go admin
输入: th   -> 匹配: theme light, theme dark, theme toggle
输入: foc  -> 匹配: focus message, focus search, focus reply
```

### 2. Tab 自动补全

- 单个匹配时：自动补全完整命令
- 多个匹配时：补全公共前缀

### 3. 命令历史

最近执行的命令会优先显示在列表顶部（最多显示 5 条历史）。

### 4. 完整帮助视图

输入 `help` 并按 Enter，将显示按分类组织的完整命令列表。点击任意命令可直接执行。

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `:` | 打开命令面板（非输入框焦点时） |
| `Esc` | 关闭命令面板或帮助视图 |
| `Tab` | 命令补全 |
| `Enter` | 执行命令 |

---

## 权限说明

- 部分命令需要登录后才可用（如 `go settings`）
- 管理员命令需要管理员权限（如 `go admin`）
- 未授权的命令不会显示在列表中
