# SPA设置和管理面板功能说明

本文档说明了在SPA前端中实现的设置和管理面板功能。

## 概述

将传统的多页面HTML设置和管理面板迁移到Vue.js单页应用(SPA)中，提供更流畅的用户体验。

## 实现的功能

### 设置页面 (`/spa#/settings`)

设置页面采用标签页组织，包含以下功能：

#### 1. 外观设置
- **主题模式切换**: 亮色/暗色模式切换
- 使用Element Plus的Switch组件
- 设置持久化到localStorage

#### 2. 功能设置
- **爱心雨效果**: 开关"2026"消息触发的爱心雨动画
- 设置同步到localStorage

#### 3. 个人资料
- **昵称编辑**: 修改显示昵称（最多64字符）
- **颜色选择**: 使用颜色选择器设置用户名颜色（支持#RGB和#RRGGBB格式）
- **徽章设置**: 设置用户徽章（如VIP、MOD等，最多32字符）
- **实时预览**: 更改立即在预览区域显示效果
- **API集成**: 通过`PUT /api/profile`提交更新

#### 4. 修改密码
- **当前密码验证**: 必须输入正确的当前密码
- **新密码设置**: 密码最小长度可在config.py中配置（默认至少6个字符）
- **确认密码**: 两次输入必须一致
- **API集成**: 通过`PUT /api/change_password`提交更新

#### 5. 账户管理
- **我的文件**: 跳转到图片/文件管理页面
- **关注管理**: 跳转到关注列表管理
- **退出登录**: 安全退出系统

### 管理面板 (`/spa#/admin`)

管理面板提供管理员所需的各种工具，仅管理员可访问。

#### 1. 管理卡片
快速访问各个管理模块：
- **用户管理**: 跳转到`/admin/users`
- **聊天管理**: 跳转到`/admin/chat`
- **帖子管理**: 跳转到`/admin/forum`
- **数据库管理**: 跳转到`/admin/db`
- **名言管理**: 跳转到`/admin/quotes`

#### 2. 系统工具
直接在SPA中执行的管理操作：
- **系统信息**: 显示内存使用、服务器时间、Python和Flask版本
- **查看日志**: 显示系统日志内容
- **清除缓存**: 清除服务器缓存（需确认）
- **备份数据库**: 创建数据库备份（需确认）
- **优化数据库**: 执行VACUUM优化（需确认）
- **重新统计文件**: 重新计算用户文件大小（需确认）

#### 3. 备份下载
- **下载项目根目录**: 创建并下载项目zip包
- **下载数据库文件**: 下载SQLite数据库文件
- **下载图片压缩包**: 打包下载所有上传的图片

#### 4. 服务器控制（可选功能）
需要在`config.py`中启用`ENABLE_SERVER_CONTROL`：
- **重启服务器**: 重启Flask应用（所有连接中断）
- **关停服务器**: 关闭服务器进程（需输入原因）

#### 5. 输出显示
- 操作结果显示在卡片中
- 成功操作显示绿色边框
- 错误操作显示红色边框
- 可关闭输出卡片

## 新增API端点

为支持SPA操作，新增以下API端点：

### `/api/profile` (PUT)
更新当前用户的个人资料
```json
{
  "nickname": "用户昵称",
  "color": "#FF0000",
  "badge": "VIP"
}
```

响应：
```json
{
  "success": true,
  "message": "个人资料已更新",
  "user": {
    "nickname": "用户昵称",
    "color": "#FF0000",
    "badge": "VIP"
  }
}
```

### `/api/change_password` (PUT)
修改当前用户密码
```json
{
  "old_password": "旧密码",
  "new_password": "新密码",
  "confirm_password": "新密码"
}
```

响应：
```json
{
  "success": true,
  "message": "密码已成功修改"
}
```

## 技术实现

### 前端技术栈
- **Vue 3**: Composition API
- **Element Plus**: UI组件库
- **Fetch API**: 异步HTTP请求
- **Reactive State**: Vue响应式数据

### 用户体验改进
1. **无刷新操作**: 所有设置更新无需页面刷新
2. **即时反馈**: 使用Element Plus的消息提示
3. **加载状态**: 按钮显示loading状态
4. **确认对话框**: 危险操作需要用户确认
5. **实时预览**: 个人资料修改实时显示效果

### 安全性
- **登录验证**: 所有API端点都需要登录
- **管理员权限**: 管理面板仅管理员可访问
- **数据验证**: 服务端验证所有输入数据
- **错误处理**: 完善的错误捕获和提示

## 样式设计

### 主题兼容性
- 支持亮色/暗色主题
- 使用CSS变量适配主题
- Element Plus组件自动适配

### 响应式布局
- 移动端友好
- 网格布局自适应
- 卡片式设计

## 使用方法

1. 访问 `/spa#/settings` 进入设置页面
2. 访问 `/spa#/admin` 进入管理面板（需管理员权限）
3. 各功能标签页/卡片点击即可使用
4. 修改设置后点击"保存"按钮
5. 查看操作结果提示

## 兼容性说明

- 保留原有的多页面版本 (`/settings`, `/admin/index` 等)
- SPA和传统版本可以并存
- 用户可以选择使用任一版本
- 数据通过同一后端API处理，保证一致性
